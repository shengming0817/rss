# #1726 旧普通 CI 作业回执协议（已删除）

本页保留 issue 的历史落点，不再描述可执行入口。#2084 已将普通 PR 切换为单一 `preflight`、固定
`check`/`test-affected`、四个闭合 integration carrier，以及稳定 `integration-critical` 与 `ci-gate`
两级 result-only 聚合。

旧的逐作业通用回执、阶段快照、额外 artifact 对账和身份绑定协议已经删除。当前 gate 不下载报告，不从
artifact 推导成功，也不允许诊断文件覆盖 failure、cancelled 或 skipped。

nextest 的 JUnit/JSON sidecar 是测试失败诊断与受控重放载体，不是 gate 输入；其当前格式见
[`202607111501-1731-nextest-test-evidence.md`](./202607111501-1731-nextest-test-evidence.md)。固定拓扑见
[`202606231530-001-ci-lane.md`](./202606231530-001-ci-lane.md)。
