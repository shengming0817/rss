# #1733 旧普通 CI 运行预算协议（已删除）

本页保留历史 issue 的文档位置。旧的逐作业阶段快照、预算判定器和独立预算 verdict 已从普通 PR 控制面
删除，不再提供可执行命令，也不是 gate 输入。

固定 `check`、`test-affected`、`integration-critical` Job 的超时继续由 workflow 与 runner 配置负责；超时
表现为该 Job 的失败或取消，并由 result-only gate 原样聚合。性能指标可以用于观察和容量规划，但不得把
失败 Job 改写为成功，也不得扩大 `PrComplete` 为 `ReleaseCheck`。
