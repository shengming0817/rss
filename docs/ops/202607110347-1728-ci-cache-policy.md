# #1728 旧 CI 写缓存控制协议（已删除）

本页仅记录历史结论。旧的按动态执行行分配唯一写入者、用独立策略表证明写入资格的控制协议已经删除，
不再是普通 PR 的执行或验收边界。

固定 `check`、`test-affected`、`integration-critical` Job 可以按共享 action 的当前实现恢复工具与构建缓存；
缓存命中与写入状态只影响性能，不能改变测试结果或 result-only gate verdict。排障不得通过放宽选择范围、
跳过失败 Job 或增加 required context 来补偿 cache miss。
