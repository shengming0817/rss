# rss-diag-context

`rss-diag-context` is an unpublished standalone-component candidate for propagating task-scoped
diagnostic correlation context in Rust applications.

Diagnostic context is observability data. It is not an identity, tenant, authentication, or
authorization source, and missing ambient context is handled without changing authorization
outcomes.

The package remains internal until its final API and same-revision package proof are completed.
Packaging metadata or a successful workspace build is not a release or publication approval.
